# 👨‍💼 Employee Management System

Live link :https://react-revision-kjyt.vercel.app/

A responsive **Employee Management System** built using React.js, Vite, React Bootstrap, and Axios. This application allows users to manage employee records with CRUD (Create, Read, Update, Delete) functionality.

## 🚀 Features

- **View Employees** – Display all employee records in a table.
- **Add Employee** – Add new employees with their details.
- **Update Employee** – Edit existing employee information.
- **Delete Employee** – Remove employee records.
- **Department Selection** – Select departments such as Full Stack, Graphic Design, UI/UX Design, and Video Editing.
- **API Integration** – Fetch and manage employee data using Axios.
- **Routing** – Navigate between pages using React Router.
- **Responsive UI** – Build a clean interface using React Bootstrap.
- **Loading & Error Handling** – Handle API requests and display error states.
